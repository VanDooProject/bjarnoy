# Copy guidelines

Rules for the words in the game's UI (en and de).

## Rejected copy

Lines that were rejected as cringe. Don't reuse them or write in their style.

- "Your grain starts counting right away. No account, nothing to install."
- „Baustein" (de) as the name of the stone/brick resource: sounds like a toy building block.
- „Das ist das ganze Tutorial. Wähle ein Feld, platziere das Gebäude, und die Kornzählung beginnt. Niemand fragt nach deinem Namen, bevor du etwas hast, das einen Namen verdient." (de, landing): a cute aside instead of an instruction.
- „Kein Konto" · „Nichts zu installieren" · „Mit einem Klick wieder weg" (de, landing chips): the "no account, nothing to install" sales pitch.
- „Das Getreide wird gezählt." (de, landing): the grain-counting line again.
- „Drei Gebäude, kein Jarl." (de, onboarding): a punchline instead of saying what to do.
- „Benenne deins über das Zeichen hier oben, und diese Insel folgt dir auf jedes Gerät." and the button „Jarl benennen" (de, onboarding): marketing tone, and it hides that this creates an account.
- „Dein Reich läuft" / „Dein Reich wartet" (de, onboarding eyebrows): slogans.
- „Ein Indie-Spiel, mit Liebe gemacht. Ohne Werbung." (de, intro landing): "made with love".
- „Gebaut zum Spielen, nicht nur zum Ansehen" (de, showcase): an English slogan carried over word for word.
- „Jedes Feature unten läuft auf derselben Engine, die du oben siehst — keine Attrappen." (de, showcase): bragging.
- „Eine echte End-to-End-Testsuite steuert einen echten Browser …" (de, showcase): bragging with "echt".
- „Logg dich morgen wieder ein, und die Welt hat sich ohne dich weitergedreht." (de, showcase): a cliché.
- „Die Portfolio-Hälfte dieser Seite — wie das Ganze tatsächlich gebaut ist." (de, showcase): "tatsächlich" filler.
- „Es gibt in diesem Spiel noch keinen Upgrade-Weg — hier wird nirgends tatsächlich Premium verkauft — also gibt es nichts weiter zu klicken. Frag denjenigen, der diese Welt betreibt …" (de, simulator): a self-aware "honest" tone.
- „Fast — eines der leuchtenden Grundstücke gehört dir." (de, landing): patronising "Fast —".
- „Landung wird gemacht…" (de, landing): a literal calque of "making landfall".
- „Das Herz der Siedlung." (de, docs, longhouse): a cliché.
- „Alles hier sind die Regeln und die Grafiken des Spiels selbst." (de, docs hub): "this is the real thing" filler.
- „Die Lager leben: … Die Regeln unten sind genau die, nach denen das Spiel läuft." (de, docs camps): the same filler.
- „Moor, Bach und See sind genau so gezeichnet wie in einer echten Welt." (de, docs bog map): the same filler.
- „Die Route hat das Spiel selbst berechnet: …" (de, docs movement): the same filler.
- „Wölfe, Eber und Schlimmeres beherrschen die freien Inseln. Jage sie und nimm dir die Beute." (de, docs): teaser
  tone, „und Schlimmeres" is a cliché.
- „Pro Siedlung bekommst du nur einen Schrein, die Wahl zählt also." (de, docs shrines): teaser tone.
- „Eine Saga aus dem Norden – gemeinsam gespielt." (de, intro landing): a slogan.
- „Stich in See, beanspruche einen Bauplatz und errichte ein Reich, das auch offline weiterwächst — …" (de, showcase):
  a sales pitch.
- „Grenzen, die wachsen" / „Echtzeit, ständig in Bewegung" / „Englisch + Deutsch, immer im Gleichschritt" (de,
  showcase): slogan titles.
- „… die Karte zu kennen ist Teil des Spiels." (de, showcase): filler.
- „Nichts ist gemeinsam — Karawanen und Schiffe bewegen Güter …" (de, showcase): opens with a puzzling claim.
- „… nichts „öffnet" eine eigene Ansicht." (de, showcase): filler.
- „Leeres Grundstück · Bjarnøy" (de, landing eyebrow).
- „Landung geglückt." / „Alle drei stehen." / „Betritt deine Siedlung" (de, landing): pathos for a tutorial step.
- „Dein Gerät wünscht weniger Bewegung …" / „dein System wünscht reduzierte Bewegung" (de): the device "wishes".
- „… ASCII-Art willkommen." (de, profile bio): cutesy.
- „Grundstück" (de): never use it.
- „Hauptschwein" (de): never use it.
- „Lager" (de) for a wildlife camp: cringe, and „Lager" already means storage.

## German terms

One German word per game concept. Use these, not the alternatives listed after them.

- Raid (mission): „Plündern", not „Überfall".
- Provisions an army carries on the move: „Proviant", not „Vorräte".
- Rune rarity "Blooded": „Blutgeweiht", not „Geblutet" (that means "bled").
- Wildlife camp: „Wildtiere" for labels and headings (reports tab, docs page), „Revier" wherever one place is meant
  („Starkes Revier", „Revier Stufe 5", „Jage in einem Revier"). Not „Lager".
- Missions as actions or choices are verbs: „Angreifen", „Plündern", „Unterstützen", „Jagen", „Ziehen", „Siedlung
  gründen". A running mission in a status view is a noun: „Angriff", „Plünderung", „Unterstützung".
- Build slots (builds that run at the same time): „Baumeister" („Kein Baumeister frei", „Wartet auf einen Baumeister",
  „2 / 3 Baumeister"). Not „Bauplatz".
- The waiting queue behind the build slots: „Warteschlange" („Die Warteschlange ist voll."). Not „Baustellenschlange"
  (not a German word).
- A player's start plot: „Startplatz". Any other tile: „Feld".
